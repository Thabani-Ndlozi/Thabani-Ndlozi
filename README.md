## Featured Projects

### Dr Vocab

An educational vocabulary platform designed for children in Grades 1–3.

The platform uses structured daily activities, audio guidance, picture matching, sentence practice, mini-stories, progress tracking, and parent-assisted learning.

**Technology:** React, Firebase Authentication, Firestore, Firebase Storage, ElevenLabs API

🌐 [Visit Dr Vocab](https://drvocab.co.za)

**Technology:** HTML, CSS, JavaScript, video-based interactions, Firebase Hosting

### RSVPly

A full-stack event management and RSVP application.

It allows organisers to create events, generate shareable RSVP links, manage attendees, check guests in, send confirmations, and review event analytics.

**Technology:** React, Vite, Firebase Authentication, Firestore

🌐 [Visit RSVPLY](https://rsvply-5f88d.web.app/)

---

### CV Salary Predictor

A machine-learning web application that analyses information extracted from a CV and predicts an estimated salary range.

The system uses information such as job title, experience, education, skills, industry, location, certifications, company size, and remote-work preferences.

**Technology:** React, FastAPI, Python, Scikit-learn, PyMuPDF, spaCy

---

### Lace Legends Store

A production e-commerce platform developed for a sneaker business.

The platform includes product management, delivery calculations, online payments, order tracking, email receipts, and an authenticated administration dashboard.

**Technology:** JavaScript, Firebase Authentication, Firestore, iKhokha Payments

---

### BC WildWatch

A wildlife-support application developed using the Microsoft Power Platform.

My contribution focused on developing an AI chatbot using Gemini through Power Automate, integrating chat history, and supporting the application's information flow.

**Technology:** Power Apps, Power Automate, SharePoint, Power BI, Gemini API
